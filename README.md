# Bybus — لوحة تحكم الإدارة

مشروع React (Vite) متصل مباشرة بقاعدة بيانات Bybus على Supabase.

## التشغيل على جهازك (قبل الرفع على GitHub)

1. لازم يكون عندك [Node.js](https://nodejs.org) متثبت (نسخة 18 أو أحدث).
2. افتح Terminal / موجه الأوامر جوه مجلد المشروع ده، واكتب:

```bash
npm install
npm run dev
```

3. هيفتحلك رابط زي `http://localhost:5173` — افتحه في المتصفح، وسجل دخول بحساب المدير العام:
   - البريد: `admin@bybus.app`
   - كلمة المرور: `Bybus#2026Secure!` (**غيّرها فور أول دخول** من إعدادات Supabase Auth)

## رفع المشروع على GitHub (بمستودع خاص به منفصل)

```bash
git init
git add .
git commit -m "بداية مشروع لوحة تحكم الإدارة"
git branch -M main
git remote add origin <رابط-المستودع-بتاعك-على-GitHub>
git push -u origin main
```

> ⚠️ **مهم جداً:** ملف `.env` فيه بيانات الاتصال بقاعدة البيانات، وهو **متضاف في `.gitignore`** فلن يترفع على GitHub تلقائياً — وده مقصود عشان الأمان. لو الـ Repository هيكون **عام (Public)**، خد بالك إنك متضيفش `.env` يدوياً بالغلط.
>
> استخدم `.env.example` كمرجع للقيم المطلوبة فقط، من غير ما تحط فيها بيانات حقيقية لو رفعته.

## البناء لنسخة الإنتاج (قبل النشر النهائي)

```bash
npm run build
```

هيطلعلك مجلد `dist/` جاهز للنشر على أي استضافة ويب (Vercel, Netlify, أو حتى GitHub Pages).
